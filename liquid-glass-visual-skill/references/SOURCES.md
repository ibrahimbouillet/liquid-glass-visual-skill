# Sources et provenance

## Sources Apple primaires

- [Apple Developer — Meet Liquid Glass (WWDC25, session 219)](https://developer.apple.com/videos/play/wwdc2025/219/) : comportement optique, lensing, interaction, adaptation aux contenus, frontières Regular/Clear, hiérarchie et accessibilité.
- [Apple — Human Interface Guidelines: Materials](https://developer.apple.com/design/human-interface-guidelines/materials) : usage modéré, variants, contexte des contrôles et accessibilité.
- [Apple Developer — Build a SwiftUI app with the new design (WWDC25)](https://developer.apple.com/videos/play/wwdc2025/323/) : adoption du matériau et adaptation pendant défilement.
- [Apple Developer — Build a UIKit app with the new design (WWDC25)](https://developer.apple.com/videos/play/wwdc2025/284/) : contrôles, navigation et barres.
- [Apple Developer — Build an AppKit app with the new design (WWDC25)](https://developer.apple.com/videos/play/wwdc2025/310/) : application au desktop et API spécifiques.

## Distinctions essentielles

1. **Propriétés Apple observées/documentées** : lensing, adaptation dynamique, hiérarchie de navigation, ombres/reflets contextuels, Regular/Clear et accessibilité système.
2. **Recommandations de ce skill** : matrice V01–V15, états de vérification, suggestions de techniques C++, fallback, seuils de qualité/performance relatifs à chaque projet.
3. **Aucune garantie de clonage exact** : le moteur privé, l'environnement matériel, les API disponibles et les réglages système influencent fortement le résultat. Les modèles et kits non-Apple produisent une interprétation du langage visuel, pas la bibliothèque propriétaire d'Apple.

Ce dépôt ne contient pas d'images, icônes, ressources ou code propriétaires Apple.
